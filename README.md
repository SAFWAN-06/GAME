# ليلة المافيا

لعبة مافيا عربية جماعية عبر الإنترنت، بواجهة RTL متجاوبة مع الهاتف والكمبيوتر، وغرف فورية ودردشة وجولات ليل ونهار.

## التشغيل محليًا

تحتاج إلى Node.js 18 أو أحدث.

```sh
npm install
npm start
```

ثم افتح `http://localhost:3000`. أنشئ غرفة وشارك رمز دعوتها أو رابطها. أضف خصوم الذكاء الاصطناعي واحدًا تلو الآخر إلى الجلسة نفسها من ردهة المضيف. تتغير واجهة صحيفة المدينة بين الليل والنهار، ولكل لاعب بطاقة هوية خاصة لا تظهر لبقية اللاعبين. الأدوار: المافيا، الطبيب، المحقق، وأهل المدينة. الغرف محفوظة في ذاكرة الخادم وتُحذف عند إعادة تشغيله.

## استضافة مجانية على Koyeb

يستضيف [Koyeb](https://app.koyeb.com/) تطبيق Node.js ويدعم WebSocket. النشر لا يحتاج ملف إعداد خاصًا: ارفع المشروع إلى GitHub، ثم أنشئ **Web Service** جديدًا واختر المستودع. يستخدم Koyeb عادةً `npm run build` للبناء، فاضبط أمر البناء على `npm install` وأمر التشغيل على `npm start`، واترك المنفذ على القيمة التي يحددها `PORT` تلقائيًا؛ الخادم يستمع إلى `process.env.PORT`.

اختر خطة **Free** والمنطقة المناسبة لحسابك. الخطة توفر خدمة ويب مجانية واحدة بسعة 512 MB و0.1 vCPU و2 GB، وتتوقف تلقائيًا بعد ساعة دون حركة. تستيقظ عند الطلب التالي، وقد يستغرق أول اتصال عدة ثوانٍ. تحتاج حساب Koyeb وربط GitHub؛ قد يطلب Koyeb بطاقة دفع للتحقق من بعض الحسابات.

غرف اللعبة وبياناتها داخل الذاكرة فقط، لذا تنتهي إذا أعادت الاستضافة تشغيل الخادم. لا تضع أسرارًا أو بيانات دفع في المستودع.
